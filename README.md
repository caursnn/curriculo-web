# Sobre 
Este projeto consiste em um currículo online desenvolvido como atividade prática da disciplina de Programação IV.
Tem como proposta um curriculo robusto, para apresentar minha formação acadêmica, experiências, habilidades e informações profissionais por meio de uma página web.

# Funcionalidades
* Apresentação pessoal
*  Formação acadêmica
*  Experiências profissionais
*  Lista de habilidades técnicas
*  Mensagem interativa de boas-vindas
*  Formulário com saudação personalizada
  
# Tecnologias usadas
Tecnologia | Utilização                            
----------  ------------------------------------- 
HTML5      | Estrutura e conteúdo da página        
CSS3       | Estilização, Flexbox 
JavaScript | Interações e comportamento dinâmico
